# v0.4.0

- 迁移至正式 `github.com/gatework/net-connector v0.9.0` 和 `go-expect v0.6.0`，不使用本地替换。
- 同步更新 pgx v5.13.0、x/sys v0.50.0、x/term v0.48.0 和 x/text v0.44.0，最低 Go 版本保持 1.26.0。
- 清单配置与 Go API 统一平台术语：`include_vendors` / `exclude_vendors` 改为 `include_platforms` / `exclude_platforms`，`vendor_overrides` 改为 `platform_overrides`，设备映射的目标 `connector` 改为 `platform`。
- `DeviceRule.Platform`、`Selection.IncludePlatforms` / `ExcludePlatforms` / `PlatformOverrides` 及 `platform.Registry` 替代旧字段和注册表类型；源清单的厂商标签 `Vendor` 保持其原始数据含义。

旧配置键不再接受，升级前需同步配置。保留未知证据、失败回执、缓存身份和禁止命令重放的语义。最低 Go 版本仍为 1.26.0；测试使用合成输入，不代表真实设备验收。
