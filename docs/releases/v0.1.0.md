# v0.1.0

首个 go-netops 发行版：go-vxlan 与 go-wireless 共用的运维领域内核，厂商无关。

- `evidence`：类型化观测状态、`Observation[T]`、来源引用、覆盖率与统一的规范 JSON 指纹。
- `assess`：严重级别、分类、发现项、`Rule[M]`/`Catalog[M]`、YAML 策略（开关、严重级别覆盖、阈值）与评估引擎；证据不完整的规则跳过，崩溃规则隔离。
- `drift`：基线、同角色多数一致、上次快照三类偏离来源。
- `change`：`Change[M]` 接口、绑定设备与配置指纹的不可变计划、信封持久化与重渲染校验。
- `apply`：合并自 go-vxlan/go-wireless 的单计划执行状态机，保留 intent/ack/uncertain、不重试/不重连/不重放/不回滚/不保存语义。
- `store`、`session`、`textscan`：私有原子持久化与检查点恢复、稳定失败码、解析辅助。

固定 go-net-connector v0.6.0 和 go-expect v0.5.0，最低 Go 1.26.0。本版为库，不含可执行文件；未进行真实设备验收。
